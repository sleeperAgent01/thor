# Proyecto Thor

Repositorio de datos y registros de correcciones del proyecto **THOR**.

## 📌 Descripción

Este repositorio contiene los datos, tablas y archivos asociados a las correcciones realizadas en el marco del proyecto **THOR**. Su objetivo es mantener un registro versionado, trazable y reproducible de todas las modificaciones aplicadas.
